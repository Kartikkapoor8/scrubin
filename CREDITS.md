# Credits

## HoloLens app (VIPER, Unity)

- **Holographic body (skin, muscles, skeleton, organs):** generated procedurally at runtime by
  `Assets/ScrubIn/Body/BodyBuilder.cs`. No third-party 3D model is used, so there is nothing to attribute or
  license. (Z-Anatomy and BodyParts3D were considered; both ship as very large Blender / multi-part archives that
  could not be converted and decimated within the hackathon time box.) The shapes are stylised, not anatomically
  exact. Simulated training only, not medical guidance.
- **TextMesh Pro essential resources** (`Assets/TextMesh Pro/`): Unity Companion License.
- **Liberation Sans font** (inside the TextMesh Pro resources): SIL Open Font License 1.1.
- **Shaders, meshes, lines:** written for this project (`Assets/ScrubIn/Visuals/`).

See `README.md` for the rest of the project's third-party table.
